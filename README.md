
# 📝 Task Manager App (React + Redux Toolkit)

A modern **Task Manager application** built using **React** and **Redux Toolkit** with full CRUD functionality, task status management, search & filter options, and localStorage persistence.

---

## 🚀 Features

- ➕ Add new tasks  
- ✏️ Edit / update existing tasks  
- 🗑️ Delete tasks  
- ✅ Mark tasks as **Completed / Pending** using checkbox  
- 🔍 Search tasks by name  
- 🎯 Filter tasks (All / Pending / Completed)  
- 💾 Data persistence using **localStorage**  
- 🌍 Global state management using **Redux Toolkit**  
- 🎨 Clean and responsive UI  

---

## 🛠️ Tech Stack

- **Frontend:** React (Vite)
- **State Management:** Redux Toolkit
- **Styling:** CSS
- **Persistence:** localStorage
- **Version Control:** Git & GitHub

## 🧠 How It Works

* Tasks are stored in **Redux global state**
* Actions like `addTask`, `updateTask`, `deleteTask`, and `toggleTask` modify the state
* Redux state is synced with **localStorage** to persist data across refresh
* UI updates automatically using `useSelector` and `useDispatch`
